WristCommand LTE 준비WristCommand LTE setup

WristCommand LTE는 본인 개발자 계정의 무료 사용량으로 인터넷(폰 경유) 명령을 쓰는 앱입니다. 처음 한 번 약 30분 준비가 필요하고(개발자 앱 승인 대기는 빼고), 폰만으로 할 수 있습니다. 아래 카드를 위에서부터 하나씩 하세요. 초록 단추 [열기]는 그 화면을 새 탭으로 엽니다 — 이 페이지는 닫지 말고 탭만 오가세요. 파란 [복사]를 누른 뒤 그 화면의 칸에 붙여넣으면 됩니다.

WristCommand LTE uses your own developer account's free usage for remote (phone) commands. The one-time setup takes about 30 minutes plus the wait for developer app approval, and can be done on a phone. Go through the cards from the top. Green [Open] opens that screen in a new tab — keep this page open and switch tabs. Tap blue [Copy], then paste into the field on that screen.

이 페이지는 인터넷으로 아무것도 보내지 않습니다. 입력한 값은 이 화면과 클립보드에만 있습니다(GitHub 아이디만 이 폰에 기억). 개발자 계정에 결제수단은 넣지 마세요 — 이 앱은 무료 사용량 안에서만 쓰도록 만들었고, 무료 사용량을 다 쓰면 그달 남은 기간은 블루투스로만 씁니다.

This page sends nothing over the internet. What you type stays on this screen and in your clipboard (only your GitHub username is remembered on this phone). Do not add a payment method to the developer account; the app is built to stay within the free usage, and once that runs out it uses Bluetooth for the rest of the month.

1차 계정 2단계 인증 켜기Turn on two-factor authentication on your car account

개발자 사이트 가입 조건입니다(이메일 인증 + 2단계 인증). 차 계정의 보안 설정에서 켭니다. 이미 켜져 있으면 넘어가세요.

The developer program requires a verified email and multi-factor authentication. Turn it on in your car account's security settings. Skip if already on.

2GitHub 계정 (무료)GitHub account (free)

공개키 파일을 올려 둘 내 웹 주소를 GitHub에 무료로 만듭니다. GitHub 계정이 이미 있으면 그 계정을 쓰세요(무료 계정은 한 사람에 하나). 없으면 [열기]로 가입합니다. 아이디에 차 제조사 이름(영문)을 넣지 마세요 — 그런 주소는 등록되지 않습니다.

You make a free web address on GitHub to hold your public key file. Use your existing GitHub account if you have one (one free account per person); otherwise sign up with [Open]. Do not put the car maker's name in your username; such addresses are not accepted.

열기 · GitHub 가입Open · GitHub sign-up

아이디를 넣으면 아래 카드의 [열기]·[복사]가 내 주소로 바뀝니다.

Once you enter it, the [Open] and [Copy] buttons below use your address.

3저장소 만들기Create the repository

열기 · 새 저장소 (이름 채워짐)Open · New repository (name filled in)
  1. 열린 화면에서 저장소 이름 칸에 아이디.github.io가 들어 있는지 봅니다. 비어 있으면 해서 붙여넣으세요.
  2. On the screen that opens, check the repository name is username.github.io. If it is empty, and paste it.
  3. 공개 범위가 Public인지 봅니다(이미 골라져 있습니다).
  4. Make sure visibility is Public (already selected).
  5. README를 추가하는 선택을 켭니다.
  6. Turn on the option to add a README.
  7. 아래쪽 Create repository를 누릅니다. (이 이름의 저장소가 이미 있다고 나오면 그 저장소를 그대로 씁니다.)
  8. Tap Create repository at the bottom. (If a repository with this name already exists, just use it.)

4공개키 만들기 (이 페이지에서)Make the public key (on this page)

비밀 키는 이 브라우저 안에서만 잠깐 생겼다가 페이지를 닫으면 사라지고, 꺼낼 수도 없습니다. 시계는 이 키를 쓰지 않습니다(명령은 시계 키로 서명합니다). 주소마다 다른 키가 필요해서 만드는 것입니다. 다음 카드를 마치기 전에 이 페이지를 닫으면 다시 만드세요.

The private half exists only inside this browser, cannot be exported, and is gone when you close the page. The watch never uses it (commands are signed with the watch key); every address just needs its own key. If you close this page before finishing the next card, make it again.

5공개키 파일 올리기Upload the public key file

열기 · 내 저장소Open · My repository
  1. 파일 목록 위의 Add file 메뉴 → Create new file.
  2. Above the file list: Add file menu → Create new file.
  3. 파일 이름 칸에 붙여넣기: .well-known/appspecific/com.tesla.3p.public-key.pem (빗금 「/」에서 폴더가 자동으로 나뉩니다.)
  4. Paste into the file name field: .well-known/appspecific/com.tesla.3p.public-key.pem (the slashes create the folders).
  5. 내용 칸에 4번에서 만든 공개키 붙여넣기 .
  6. Paste the public key from card 4 into the content box .
  7. Commit changes... → 뜨는 창에서 현재 가지(main)에 바로 올리는 선택 그대로 두고 Commit changes.
  8. Commit changes... → in the dialog, keep committing directly to the current branch (main) → Commit changes.

6점 폴더 보이게 하기 (.nojekyll)Let the dot-folder be served (.nojekyll)

열기 · 내 저장소Open · My repository
  1. 다시 Add file → Create new file → 파일 이름 .nojekyll → 내용은 비워 두고 Commit changes... → Commit changes.
  2. Again Add file → Create new file → file name .nojekyll → leave the content empty → Commit changes... → Commit changes.

점(.)으로 시작하는 폴더를 웹에 보이게 하는 빈 파일입니다. 이미 이 저장소로 블로그 같은 사이트를 쓰고 있다면 .nojekyll 대신 _config.yml 에 include: [".well-known"] 한 줄을 더하세요 — .nojekyll 을 넣으면 그 사이트가 꺼질 수 있습니다.

An empty file that lets folders starting with a dot be served. If this repository already hosts a site (e.g. a blog), add the line include: [".well-known"] to _config.yml instead; .nojekyll could switch that site off.

7웹 게시 켜기·확인Turn on and check publishing

열기 · 내 저장소Open · My repository
  1. 저장소 이름 아래 Settings (안 보이면 메뉴 「…」 안) → 왼쪽 목록의 Pages.
  2. Under the repository name: Settings (inside the “…” menu if hidden) → Pages in the sidebar.
  3. Build and deployment의 Source가 Deploy from a branch이고 가지가 main, 폴더가 / (root)인지 봅니다. 아니면 그렇게 고르고 Save.
  4. Under Build and deployment, make sure Source is Deploy from a branch, branch main, folder / (root). If not, pick them and tap Save.
  5. 몇 분(최대 10분) 뒤 아래 [열기]를 눌러 「BEGIN PUBLIC KEY」 글자가 보이면 됩니다. 안 보이면 잠시 뒤 다시 여세요.
  6. After a few minutes (up to 10), tap [Open] below; you should see “BEGIN PUBLIC KEY”. If not, try again a little later.
열기 · 내 공개키 주소 확인Open · Check my key address

내 도메인을 쓰는 경우 3·5·6·7 카드 대신, 그 사이트의 같은 경로(/.well-known/appspecific/com.tesla.3p.public-key.pem)에 4번 공개키를 올리고 아래 [열기]로 확인하세요.If you use your own domain, skip cards 3, 5, 6 and 7: put the key from card 4 at the same path (/.well-known/appspecific/com.tesla.3p.public-key.pem) on that site and check it with [Open] below.

바로 열리지 않으면 앱 목록의 「새 애플리케이션 만들기」(Create New Application)를 누르세요.

9Client ID·Client Secret 가져오기 (승인 뒤)Get the Client ID and Client Secret (after approval)

열기 · 내 앱 목록Open · My applications
  1. 「개발자 애플리케이션」(Developer Applications) 화면에서 내 앱의 「세부내역 확인」(View Details).
  2. On Developer Applications, tap View Details on your app.
  3. 「자격 증명 및 API」(Credentials & APIs) 탭의 「OAuth 2.0 고객 ID」(OAuth 2.0 Client ID) 칸을 봅니다.
  4. Open the Credentials & APIs tab and find OAuth 2.0 Client ID.
  5. 「고객 ID」(Client ID) 옆 복사 아이콘(겹친 네모)을 누르고 → 이 페이지로 돌아와 아래 첫 칸에 붙여넣기.
  6. Tap the copy icon (two squares) next to Client ID → come back here and paste into the first box below.
  7. 「고객 비밀번호」(Client Secret) 옆 눈 아이콘을 눌러 값을 보이게 한 뒤, 그 값을 길게 눌러 전부 선택·복사 → 아래 둘째 칸에 붙여넣기.
  8. Tap the eye icon next to Client Secret to show it, long-press to select all and copy → paste into the second box below.

Client Secret은 남에게 보여 주거나 메신저로 보내지 마세요. 이 페이지는 저장하지 않습니다.

Never show or message the Client Secret to anyone. This page does not store it.

10한 줄로 묶어 복사Bundle into one line and copy

Client ID·Client Secret·내 주소를 시계가 받을 수 있는 한 줄로 묶습니다.

This bundles the Client ID, Client Secret and your address into one line the watch can take.

11시계로 보내기Send to the watch

  1. 시계에서 WristCommand LTE를 열고 내 개발자 계정을 누릅니다(차가 없으면 첫 화면, 있으면 「설정·더보기」 안). 개인정보 동의 뒤 폰 알림을 누릅니다.
  2. On the watch open WristCommand LTE and select My developer account (first screen if no car yet, otherwise in Settings & more). After the personal-data consent, tap the phone notification.
  3. 열린 화면 칸에 붙여넣기 → [시계로 보내기]. 시계가 주소를 등록합니다(몇 초).
  4. Paste into the box that opens → [Send to watch]. The watch registers your address (a few seconds).
  5. 곧 오는 두 번째 알림 → 차 계정으로 로그인 → 권한을 전부 허용 → 시계에 차 이름이 뜨면 끝입니다.
  6. Tap the second notification → sign in with your car account → allow all permissions → done when your car name appears on the watch.

12마무리Finish

[클립보드 비우기]를 누르세요(한 줄에 Client Secret이 들어 있습니다). 키보드의 클립보드 기록이나 다른 기기와 공유되는 클립보드를 쓰신다면 그쪽 기록도 지워 주세요.

Tap [Clear clipboard]; the line contains your Client Secret. If your keyboard keeps a clipboard history or your clipboard syncs to other devices, clear those too.

블루투스 키(차 옆에서 쓰는 시계 키)는 따로 키카드로 등록합니다. 인터넷 명령도 이 시계 키로 서명하므로 키 등록이 필요합니다. 값을 지우려면 시계의 「내 개발자 계정 지우기」를 누르세요.

The watch key is still registered separately with your key card; remote commands are signed with it too. To delete the values, use “Remove my developer account” on the watch.
